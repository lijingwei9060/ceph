# Phase 7: 存储池模块

## 工作目标

迁移存储池列表、创建、编辑页面。存储池是 Ceph 的核心概念，创建表单涉及 PG 计算、设备类选择、CRUSH 规则等复杂逻辑，需要确保与 Angular 版本行为一致。

完成标志：存储池模块下的所有页面可正常访问和操作，PG 计算器输出与 Angular 版本一致。

## 工作内容

### 7.1 迁移存储池管理

- 存储池列表 → `src/features/pool/pages/pool-list.tsx`
  - 使用 shadcn DataTable：分页 + 排序 + 筛选
  - 列：名称、类型（副本/纠删码）、副本数/EC 配置、PG 数、已用/可用/使用率
  - 操作：创建、编辑、删除
- 存储池创建 → `src/features/pool/components/pool-form.tsx`
  - 基本配置区：
    - 名称
    - 类型选择：副本 (replicated) / 纠删码 (erasure-coded)
    - PG 数量（含 PG 计算器）
    - 设备类 (device class)：ssd/hdd/nvme/空
    - CRUSH 规则
  - 副本类型配置：
    - 副本数 (size)
  - 纠删码类型配置：
    - 纠删码配置文件选择（下拉列表，从 `/api/erasure_code_profile` 获取）
    - 或创建新的纠删码配置文件（弹窗或内联表单）
  - PG 计算器：
    - 复用 Angular 版本的 PG 计算逻辑
    - 输入：OSD 数、OSD PG 数、预期存储池数、预期副本数
    - 输出：建议 PG 数
  - 高级配置区：
    - 配额 (max_bytes, max_objects)
    - 压缩模式
    - 节点亲和性
  - 使用 `react-hook-form` + `zod` 验证
- 存储池编辑 → 复用创建表单，预填当前值
